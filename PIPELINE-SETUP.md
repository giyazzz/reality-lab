# REALITY LAB — zero-paid-API workflow

This version uses public research endpoints, open-source eSpeak NG, FFmpeg, and GitHub Actions. No Anthropic or ElevenLabs keys are required.

## Run
1. Open the repository Actions tab.
2. Select Create REALITY LAB free episode.
3. Click Run workflow and enter a topic.
4. Wait for the workflow, then download the reality-lab-free-episode artifact.

## Important limitations
- Research currently uses a Wikipedia summary and OpenAlex paper metadata.
- The script is a structured research draft, not an AI-written full-length documentary. It must be expanded and fact-checked.
- eSpeak NG is free but sounds robotic.
- Rendering currently makes storyboard-card scenes, not the full 3D Three.js character animation.
- Upload manually through YouTube Studio after reviewing the episode. No paid YouTube API setup or automatic public publishing.
- GitHub Actions public repositories generally have free standard-runner usage, subject to GitHub limits and policy. This project cannot guarantee unlimited free compute.
- Public research APIs have their own fair-use and availability limits.
